  + 这个得设计的好点，并且量不能太大
  + 打弹，当时的判断和是否击中两个
  + 将两个值降温处理后softmax了，然后随机数比较和动作的大小
  + 更谨慎决策
+ 仿真

+ 状态
  + 前面5步的动作
  + 开局5步不训练，空5步
  + 加入动作
+ 奖励
